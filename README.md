# C++ 笔记 · 少儿编程（GESP 1–8 级）

在线访问：<https://amelia-tom.github.io/cpp-notes-studio/>

> 当前线上版本由 `gh-pages` 分支静态部署；`main` 分支只放源码。仓库内的 `.github/workflows/deploy.yml` 会在推送后自动构建并发布（需给令牌 `workflow` 权限后启用）。

面向少儿编程 / 信息学入门的 C++ 学习笔记 Web 应用。按 CCF **GESP C++ 1–8 级**认证标准组织内容，覆盖「读教材 → 自讲自评 → 做专项 → 开模拟卷 → 错题复盘 → 看进度」的完整闭环。

## 功能

- **35 章教材级知识点**：每章含概念讲解、生活类比、语法要点、3 条易错对照（错写法 / 正确写法 / 原因）、逐行注释代码模板、例题（思路·代码·时空复杂度·一句话收获）、课后任务。
- **知识地图**（`/map`）：35 章按真实技术依赖连成 DAG（61 条边、11 层拓扑深度），悬停点亮整条前置/后续链，支持阶段筛选、缩放、标记已学；节点右上角以红色「错 N」标出该章错题数，页面底部还有按错次排序的「复习优先队列」；选中章节后可「以这章为目标」，图上按 1→n 编号高亮通往它的完整链路，并给出步数、总时长与完成进度，学习计划可一键复制 Markdown 或下载 .md。
- **GESP 八级大纲页**（`/gesp`）：每级官方知识内容、知识目标、易错提醒、对应章节、本级覆盖率，一键跳章节或开练。
- **章节笔记导出**：章节页的「导出本章笔记」会把这一节完整落成一份 Markdown —— front matter（`cpp / gespN / 章节 id` 标签）、概念、类比、语法要点、逐行注释模板、易错点（❌ 错法 / ✅ 写法 / 为什么）、关键点、例题（含思路与复杂度）、本章自测题，答案与解析统一放在文末当练习卷用，最后是作业清单；文件名形如 `07-循环结构-2026-11-24.md`，可直接拖进 Obsidian 或打印。知识点列表页的「导出本页笔记」把当前筛选结果（阶段、关键字、只看待复习都算）拼成一份合集：front matter + 目录（每节的时长与 GESP 级别）+ 各章正文（标题降一级、按 `---` 分隔），文件名形如 `讲义-basic-2026-11-24.md`，适合整本打印当讲义。
- **代码高亮 + 注释开关**：highlight.js（Xcode Light 配色）、行号、C++17 标签、一键复制；可隐藏全部行尾注释进入「自测模式」。
- **自讲自评**：三档自评（讲得清 / 有几处卡壳 / 只看懂一半），计入能力雷达。
- **练习与模拟卷**：按章节、按阶段、按 GESP 级别专项练习；每级模拟卷固定 15 题（10 选择 + 5 填空），计时、按题型统计正确率、记录历史最好成绩。
- **程序阅读**（`/reading`）：43 道按 GESP 1–8 级分级的题，分「猜输出」29 道与「程序填空」14 道两类，每题都经过 g++ 编译运行校验；支持按级别 + 题型筛选、只重做错题，答完立刻给逐行推演与考点。进入时带 `?from=mistakes[&topic=…]` 会冻结当轮阅读错题重练（答对自动出本，页面顶部显示重练横幅并回到错题本）。
- **错题本 / 进度页**：自测错题与程序阅读错题统一归集，可单条移除；自测错题额外支持按章节筛选（`/mistakes?topic=<章节>`，顶部章节胶囊按错题数排序），43 道程序阅读题也都登记了所属章节（`READING_TOPIC`），所以章节筛选同时覆盖自测与阅读两类错题，阅读错题卡上会标出章节胶囊；知识地图的「重做错题 / 去错题本重做」会直达该章错题，节点上的「错 N」角标也把阅读错次算进去了，筛完没错了也能就地跳去本章同类题；错题本顶部还有「重练这 N 道自测错题」，会把当前章节（或全部）的错题按错次从高到低拼成一组小卷（`/practice?from=mistakes[&topic=…]`），答对自动移出错题本，全清后再点「再来一组」会直接回错题本；程序阅读的错题也能这样重练（`/reading?from=mistakes[&topic=…]`）；每答完一组重练都会落一条轮次记录（`review-v1`），进度页的「错题重练」卡片给出最近 5 轮平均正确率与逐轮成绩，可点回对应章节。重练结算页还有一张收尾卡：本章还有错题就先列出来并给两条再练入口；清空了就按依赖关系推荐下一章（可用 `/map?target=<章节>` 直接在地图上打开通往它的链路），并可一键把本章标记为「已学」。进度页的重练卡片还带一条近 10 轮正确率走势条。错题本顶部还有一个「导出 Markdown」：按当前筛选范围（全部或某一章）导出一份带 YAML front matter 的笔记，先按章节、再按「自测 / 程序阅读」分组，每题附选项、正确答案与解析，程序阅读题带完整代码块和你当时的填答——直接丢进 Obsidian 或打印都行。进度页含完成度、能力雷达、GESP 级别覆盖、模拟卷成绩表，以及程序阅读的 8 级覆盖进度与累计正确率；顶部还有一张「学习节奏」卡片：把自测、重练、阅读、模拟卷四份记录按自然日归并，给出连续学习天数（今天没练会提示「做一组就续上」）、最近 14 天每日练习量柱状条（今天高亮）与最近 7 天的做题数/正确率/重练组数/阅读题数。卡片右上「导出本周报告」会生成一份周报 Markdown：概览、7 天每日明细表、本周薄弱点（正确率低于 80% 的章节）、待复习错题按章节分布、下周建议（薄弱章节 + 错题最多章节 + 下一节，自动去重）、课程进度，文件名形如 `周报-2026-11-24.md`。

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS v4 + shadcn/ui + lucide-react + recharts，数据全部本地存储（localStorage），无后端。

视觉上走 **iOS 26 液态玻璃（Liquid Glass）** 取向：底色是几团极淡的蓝/雾光叠在纸白上（`body` 的固定径向渐变），内容卡片用 `.surface`、悬浮侧栏用 `.glass-rail`——半透明白做玻璃本体、`backdrop-filter: blur() saturate()` 做磨砂、顶部内高光 + 左上斜向反射亮带 + 外圈柔影做边缘折射，圆角统一收到 18/22px。整页只保留一个蓝（`#0071E3`）做交互与数据色，玻璃本身保持中性，避免发紫或整页发蓝。

动效只做「玻璃该有的反应」这三处：卡片滚进视口时有一道极淡的高光斜着扫过（`animation-timeline: view()`，不支持的浏览器退回静态高光）；按钮按下时轻微收缩并微提亮（`scale(0.972)` + `brightness`，尊重 `prefers-reduced-motion`）；知识地图的节点改成半透明玻璃卡片——顶部白到透明的高光层 + 柔投影，已学节点带一层淡蓝，选中的那枚描边加粗成实心蓝。

## 本地运行

```bash
npm install

npm run build
npm run lint       # tsc + eslint
```

## 数据与目录

- `src/data/topics/`：章节内容（`basic` / `cert` / `contest` / `gesp1`–`gesp4`）
- `src/data/gesp.ts`：GESP 八级大纲与章节映射
- `src/data/map.ts`：知识地图的前置关系、拓扑分层与链路查询
- `src/data/questions.ts`：自测题 129 道（单选 / 填空）
- `src/pages/`：首页、知识点列表、章节详情、练习、错题本、进度、GESP 大纲
- `src/lib/markdown.ts` / `mistakes-export.ts` / `topic-export.ts`：Markdown 导出的公共件（下载、代码块包裹、时间戳）与三份导出内容（错题本、整章笔记、筛选合集）
- `src/lib/activity.ts`：学习节奏的纯计算（按自然日归并四份记录、连续天数、最近 7 天汇总）
- `src/lib/weekly-report.ts`：周报排版（概览 / 每日明细 / 薄弱点 / 错题分布 / 下周建议）

## 存储键

`cpp-notes-studio:progress-v1`（进度/错题/练习记录）、`cpp-notes-studio:reading-v1`（程序阅读逐题记录）、`cpp-notes-studio:review-v1`（错题重练轮次）、`cpp-notes-studio:prefs-v1`（注释开关）、`cpp-notes-studio:selftalk-v1`（自讲自评）、`cpp-notes-studio:exam-v1`（模拟卷成绩）。
